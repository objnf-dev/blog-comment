- “EQ调节范围应小于3db或者6db”：不正确。应该依照素材的特性，确定EQ的调节范围。
- “EQ应该多做减法（降低声音响度）少做加法（提升声音响度）”：不正确。加法和减法没有必然的使用要求，多数情况下加法合成器更加符合工作流程。
- 过度扫频：错误。任何过度使用EQ的操作都是错误的，淹没声音特点，而且会习惯性的使用不必要的EQ。-> 只在需要进行EQ处理的时候使用EQ
- 做EQ时尽量不要Solo，注意“上下文”。
